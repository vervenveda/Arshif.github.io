# Assessment Framework

## Evidence
- source cards;
- artifact/inscription dossiers;
- chronology maps;
- comparative source essays;
- manuscript-witness exercises;
- historiography matrices;
- annotated bibliographies;
- digital evidence atlases;
- research papers;
- oral defenses.

## Core 12-Week Course
The original weekly quizzes remain:
- 2 True/False
- 2 Multiple Choice
- 1 Essay / reflection
per week.

## Competencies
Each formal course records:
- Not observed
- Developing
- Secure

No composite faith score is produced.
