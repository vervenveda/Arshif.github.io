# Content Guide

## Adding an Evidence Anchor

Record:
- label;
- object/text/site;
- source institution;
- catalog/reference number if available;
- date;
- source type;
- direct evidence;
- bounded interpretation;
- debate/uncertainty;
- URL.

## Adding Context Literature

Always label the collection/tradition:
- Hebrew Bible / Tanakh
- Catholic Deuterocanon
- Orthodox collection
- Protestant Old/New Testament
- Second Temple Jewish literature
- Greco-Roman author
- later Christian / Jewish reception source

Do not present all canons as identical.
