# PROSE Editing Suite Integration

## Repository
`https://github.com/vervenveda/proresource_hub.github.io`

## Editor target
`https://vervenveda.com/proresource_hub.github.io/#prose`

## Appropriate Philosophy Hall uses
- thesis paragraphs;
- objections and replies;
- comparative essays;
- seminar papers;
- source-analysis prose;
- research sections;
- public-philosophy writing;
- capstone/thesis drafts.

## Handoff
The Hall provides **Copy Draft + Open PROSE**.

The browser attempts to copy only the text the learner explicitly placed into the bridge, then opens PROSE.

Separate static sites should not pretend to exchange private writing invisibly.
