# Assessment Framework

## Evidence Types
- question journal;
- concept definition;
- argument reconstruction;
- counterexample;
- close reading;
- Socratic dialogue;
- comparative analysis;
- ethical case analysis;
- seminar participation;
- oral defense;
- research question;
- source evaluation;
- annotated bibliography;
- objection/reply paper;
- sustained philosophical essay;
- public philosophy project;
- capstone/thesis.

## Competency Observation
Each competency is stored as:
- Not observed
- Developing
- Secure

## Suggested Formal-Course Weighting
Teachers may adapt:
- 25% reading / annotation / source work
- 25% arguments / short analytical writing
- 25% seminar / dialogue / oral defense
- 25% major paper / project / portfolio

Research-heavy 403 / 501 / 502 / 503 / 601 / 602 / 603 should shift weight toward research and sustained writing.

The Hall itself does not award official transcript credit.
