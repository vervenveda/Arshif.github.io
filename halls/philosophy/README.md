# ARSHIF · Khaemenes Academy Philosophy Hall 101–603

A centered, breathable **world-philosophy archive and course ladder from middle school through graduate-style independent study**.

## Preserved from the original Hall

- **40 original World Wisdom modules**
- **84 thinkers / wisdom keepers**
- **12 schools / branch maps**
- **26 timeline entries**
- **28 glossary terms**
- **12 original source-library entries**
- **15 preserved quiz questions**
- module completion
- personal Philosophy Journal
- per-module and per-thinker dossier notes
- public reading/reference links
- original legacy localStorage keys

The source Hall already described philosophy as world-centered rather than a narrow Western canon. This release preserves that foundation while turning the original single course into a reusable 101–603 ladder.

## Centered Khaemenes Design Standard

This build intentionally avoids the earlier sidebar/dashboard density.

It uses:
- centered chamber headings;
- centered search and filters;
- symmetrical 3 → 2 → 1 card grids;
- equal card geometry;
- 7 / 11 / 21 / 33 / 55 / 66 spacing rhythm;
- restrained typography;
- large breathing spaces between chambers;
- centered modals, tools, controls, and portfolio sections.
