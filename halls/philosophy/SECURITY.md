# SECURITY

This is a static local-first educational application.

Do not commit:
- passwords;
- API keys;
- authentication tokens;
- protected student records;
- private research records;
- unpublished writing that should remain confidential.

Browser localStorage is convenient but is not a secure academic-record database.

A future NAIB/student-record bridge should use authenticated server-side authorization rather than secrets embedded in static HTML.
