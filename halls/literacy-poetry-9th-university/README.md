# ARSHIF · Khaemenes Academy Poetry Hall 101–603

A flexible poetry resource and formal course ladder from **middle school through graduate-style independent study**.

The uploaded Hall already contained a comprehensive world-poetry archive, a 40-module course, Poem Lab, timeline, glossary, quiz, source vault, favorites, notes, and local progress. This package preserves those systems and adds a scalable 18-course architecture.

## Preserved

- 176 poetry dossiers
- 40 original resource modules
- Archive search and filters
- Living-traditions guidance
- Copyright guidance
- Poem Lab
- Timeline
- Glossary
- Quiz
- Source Vault
- Original `APH_notes`, `APH_favs`, and `APH_progress` browser storage

## Course Ladder

- 101–103 · Middle School
- 201–203 · High School
- 301–303 · Advanced High School / College Bridge
- 401–403 · Undergraduate Foundations
- 501–503 · Advanced Undergraduate
- 601–603 · Graduate-Style / Independent Scholar

The 600-series is internal Khaemenes numbering and does **not** claim accredited graduate credit.
