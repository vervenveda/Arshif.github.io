## Copy Draft + Open PROSE
The Hall copies the learner-selected text to the clipboard when permission is available and opens ProResource Hub.

This is intentional. Separate static websites should not pretend that private student text has been transferred invisibly across origins.

A future authenticated data bridge could provide protected document handoff. Tokens and private student documents should not be embedded in static HTML.
