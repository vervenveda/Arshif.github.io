# ProResource / PROSE Integration

## Repository
`https://github.com/vervenveda/proresource_hub.github.io`

## Public Hall URL
`https://vervenveda.com/proresource_hub.github.io/`

## Intended Uses
PROSE may be used for:
- public-source research essays;
- lesson plans;
- source criticism;
- metadata documentation;
- archive policy memos;
- reflection;
- capstone prose;
- bibliography commentary.

## Do Not Paste
Do not paste:
- restricted or sacred knowledge;
- unconsented interviews;
- private community records;
- protected student/community data;
- unpublished knowledge that should remain confidential;
- material the learner lacks authority to reproduce.

## Handoff
The Hall uses an explicit **Copy Draft + Open ProResource** action rather than silently moving text between separate static sites.
