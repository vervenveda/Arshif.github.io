1. Upload all package contents so `index.html` is at repository root.
2. Commit to `main`.
3. Enable GitHub Pages from the main branch/root.
4. Test all Hall tabs.
5. Test every course card.
6. Test dossier search/filter/open/favorite/note persistence.
7. Test all 32 resource modules.
8. Test competencies.
9. Test Storywork Studio and Research/Data Governance tools.
10. Test quiz and portfolio export.
11. Verify ProResource opens correctly.

No build step is required.

Do not commit credentials, private student records, unconsented interviews, protected Indigenous data, or restricted cultural knowledge.
