## Research / Data Governance

The Hall includes current reference pathways for:

- Smithsonian Native Knowledge 360°
- Common Core history/social-studies literacy benchmarks
- Global Indigenous Data Alliance CARE Principles
- Local Contexts Traditional Knowledge / Biocultural Labels
- First Nations OCAP® principles, explicitly scoped to First Nations contexts
- AIATSIS Code of Ethics for Aboriginal and Torres Strait Islander Research, explicitly scoped to those contexts
