# SECURITY

This is a static GitHub Pages educational application.

## Never store in the repository
- passwords or tokens;
- API credentials;
- private learner records;
- unconsented oral-history recordings/transcripts;
- restricted or sacred community knowledge;
- culturally sensitive data whose governance is unclear;
- private contact information for community participants.

## Browser localStorage
Local storage is convenient, not a secure research repository.

Use it only for ordinary learner notes that are appropriate to retain on the device.

## Future Remote Integration
Any future NAIB, archive, research, or community-data bridge should include:
- authentication;
- authorization;
- community governance/access rules;
- encryption;
- retention/deletion rules;
- auditability;
- correction/takedown mechanisms;
- explicit consent and purpose limitations.
