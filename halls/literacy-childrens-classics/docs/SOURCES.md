## Source Use

These links are used for:

- reading access where lawful;
- library discovery;
- public-domain discovery;
- standards orientation;
- reading-level terminology;
- curriculum comparison;
- educator and family reference.

## Maintenance

Because national curricula, URLs, terminology, and reading-level documentation can change, these references should be reviewed periodically.

This repository does not claim that every linked framework is legally required for every Khaemenes learner.

Formal requirements remain dependent on the learner’s jurisdiction and educational arrangement.
