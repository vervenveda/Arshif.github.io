# ARSHIF · Khaemenes Academy · Palimpsest Vault 101–603

A centered, quiet, archival learning Hall for **lost, fragmented, suppressed, challenged, disputed and recovered works**.

The source page describes the Vault as a register of works “burned, buried, fragmented, or pushed to the edges of public memory” and states that it does not erase anyone's canon—it simply remembers.

## Source Hygiene
The rebuilt Vault deliberately distinguishes public-domain access from copyrighted access. Questionable direct full-text links for modern copyrighted books were not carried forward. Copyrighted works use library/discovery or rights-respecting pathways.
