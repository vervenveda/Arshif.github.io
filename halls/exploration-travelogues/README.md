## Design Standard

This release uses the centered Khaemenes Hall language from the start:

- no permanent sidebar;
- centered search and filters;
- centered Hero and section titles;
- equal card geometry;
- symmetrical 3 → 2 → 1 grids;
- paired 2 → 1 learning-tool grids;
- 7 / 11 / 21 / 33 / 55 / 66 spacing rhythm;
- restrained gold, navy, sage, violet, sand and rose hierarchy;
- large breathing spaces between chambers.
