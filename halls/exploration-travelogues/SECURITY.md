# SECURITY

Static GitHub Pages cannot securely store credentials or protected records.

Do not commit:
- passwords or API tokens;
- private learner records;
- private precise-location data;
- confidential interview material;
- protected cultural knowledge;
- unpublished work that should remain private.

Browser localStorage is useful for ordinary personal notes but is not a secure research database.

A future authenticated NAIB/GIS/data bridge should implement server-side authorization, encryption, retention/deletion rules and appropriate privacy controls.
