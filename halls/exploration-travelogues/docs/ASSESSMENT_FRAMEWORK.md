# Assessment Framework

## Eleven Competencies
The Hall tracks:
- spatial thinking;
- cartography;
- source criticism;
- travel writing;
- empire/power;
- cultural/translation ethics;
- mobility/forced movement;
- environment/field observation;
- comparative geography/scale;
- research/data/GIS;
- synthesis/capstone.

Each course may record each competency as:
- Not observed
- Developing
- Secure

## Evidence Types
- route maps;
- map/source analyses;
- reading journals;
- travelogue close readings;
- field notebooks;
- comparative route studies;
- counter-archives;
- ethical dossiers;
- tourism audits;
- environmental observations;
- annotated bibliographies;
- GIS/data plans;
- researched travel writing;
- digital atlases;
- capstones and oral defenses.

## Boundary
Completion inside this Hall is a learning record, not automatic external academic credit.
