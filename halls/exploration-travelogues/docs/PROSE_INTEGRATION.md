# PROSE Integration

## Repository
`https://github.com/vervenveda/proresource_hub.github.io`

## Editor
`https://vervenveda.com/proresource_hub.github.io/#prose`

## Appropriate Uses
- researched travelogue;
- field reflection;
- map/source analysis;
- comparative route essay;
- environmental writing;
- methods section;
- historiographic paper;
- thesis/capstone.

## Handoff
The Hall provides **Copy Draft + Open PROSE**.

It copies only learner-selected text when clipboard permission is available and then opens PROSE. No hidden cross-origin transfer is claimed.
