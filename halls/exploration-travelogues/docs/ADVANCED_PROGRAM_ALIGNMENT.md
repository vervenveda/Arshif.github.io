# Advanced Program Alignment

## AP Human Geography Bridge
The current AP Human Geography framework includes skill categories in:
1. Concepts and Processes
2. Spatial Relationships
3. Data Analysis
4. Source Analysis
5. Scale Analysis

Travelogues 301 deliberately exercises those skills through maps, routes, data/source interpretation and scale.

Official reference:
https://apcentral.collegeboard.org/courses/ap-human-geography/course-audit

This repository does **not** claim AP Course Audit authorization.

## IB Geography Bridge
IB Geography integrates physical and human geography, scientific and socio-economic methodologies, global issues and case studies across local, regional, national and international scales.

Travelogues 301–303 use comparable inquiry habits while retaining their distinct travel-writing/spatial-humanities identity.

Official reference:
https://www.ibo.org/programmes/diploma-programme/curriculum/individuals-and-societies/geography/

This repository does **not** claim IB authorization.
