# Deployment

This repository is a static GitHub Pages application.

## Publish

1. Upload all repository files with `index.html` at the root.
2. Commit to `main`.
3. Open **Settings → Pages**.
4. Publish from the `main` branch / root.
5. Open the public URL.
6. Test search, filters, dossiers, notes, progress, exports, and mobile layout.

## No Build Step

No Node package, bundler, framework, or external JavaScript library is required.

## Do Not Commit Secrets

Do not place API keys, passwords, student records, email credentials, or private tokens in this static repository.
