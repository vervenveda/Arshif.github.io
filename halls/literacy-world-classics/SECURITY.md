# SECURITY

This is a static, local-first educational repository.

Do not store:

- passwords;
- API keys;
- private tokens;
- student personally identifying information;
- protected academic records;
- medical data;
- government identifiers

inside the repository or browser source.

The portfolio export is learner-controlled and local.

A future remote NAIB/student-record integration should use authenticated server-side authorization rather than embedding credentials in this page.
