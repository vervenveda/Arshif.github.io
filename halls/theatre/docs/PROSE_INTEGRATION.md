# PROSE Editing Suite Integration

Target:
`https://vervenveda.com/proresource_hub.github.io/#prose`

Use PROSE for:
- original monologues/scenes;
- plays;
- dramaturgy;
- director notes;
- design rationale;
- rehearsal reflection;
- theatre criticism;
- research;
- capstone/thesis writing.

Do not paste protected scripts merely to obtain an edit. Work from your own writing, public-domain text where lawful, or properly licensed/authorized material.
