# MATRIX CORRIDORS

The rebuilt ARSHIF root adds eleven deliberate corridors rather than turning the archive into an undifferentiated repository wall.

| Corridor | Role in the knowledge matrix |
|---|---|
| The Halls | canonical ARSHIF curriculum/research Hall directory |
| Khaemenes Academy | school-family learning gateway |
| Khaemenes Higher Learning | university-oriented continuation |
| PROSE Editing Suite | writing, editing, research drafting |
| PLERA Search | discovery and public-resource search |
| The Verifier | verification and evidence discipline |
| 333 Network | communication, community, creation, infrastructure |
| NAIB | public intelligence, mentors, specialists, verification |
| Firmament Law | legal and civic research |
| The Refrain | music, reflection, creative expression |
| Bazaar Art | visual creation and artistic response |

## Hall-to-Matrix crosslinks
The nine canonical Hall records now carry optional `related` links. These appear inside each Hall's Research Scope modal as **Related Matrix Corridors**.

Examples:
- Poetry → PROSE · The Refrain · Bazaar Art
- Philosophy → Firmament · The Verifier · Higher Learning
- Bible & History → Faith collection · PLERA · The Verifier · Academy
- Travelogues → River to Road · PLERA · Academy · Higher Learning
- Theatre → PROSE · Bazaar Art · The Refrain · Academy
- Palimpsest Vault → The Verifier · PLERA · PROSE · Firmament

No automatic data transmission is implied by these links.
